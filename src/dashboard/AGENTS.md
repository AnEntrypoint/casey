# AGENTS.md (src/dashboard)

Rationale for the operator console that code cannot say for itself. Root `AGENTS.md` covers the access ladder, the PII allowlists and the field-login fence; this file does not repeat them. Every line is true of the tree NOW.

## Shell and caching (server.js)

- `SHELL_BUILD_ID` hashes size+mtime of `public/`, the linked bundles, the module graph, the resolved brand, the tile URL and the vocabulary; the service-worker cache name carries it. Any new input to the served shell must be hashed in, or the worker keeps serving old bytes.
- Brand, tile URL, vocabulary and the generated modulepreload block are rewritten into the SERVED bytes only, never into `index.html` on disk (it stays casey's default and `brand.js` reads it as a fallback). Preloads carry no `crossorigin` (it doubles every fetch), cover static imports only, and must never reach `/design/dist/247420.js` (no `/design-sdk-shim.js` route, no importmap entry for it).
- Static files revalidate every time (no URL carries a content hash); the service worker is the speed layer, and `/api/`, `/report` and basemap tiles are never in Cache Storage. `skipWaiting` is deliberate.
- Order matters: the error middleware goes LAST and never echoes `err.message` or a stack; the WhatsApp webhook goes FIRST (exempt from compression, `express.json`, session, CSRF and the auth gate; it carries its own HMAC). `compressResponses` is hand-rolled: 200 only, always sets `Vary`, drops `Content-Length`, streams.
- Behind a reverse proxy set `CASEY_TRUST_PROXY_HOPS` to the real hop count: unset, every farmer shares one rate-limit bucket; too high, `X-Forwarded-For` can be spoofed.
- CSV export neutralises a leading `= + - @` and quotes a bare `\r`. `/tiles` stays behind the auth gate (an ungated tile route is an open proxy onto OSM); never serve blank tiles; keep the User-Agent, Referer, 7-day floor, zoom cap and no prefetch (OSM policy).

## Printables and brand (server.js, brand.js)

- A printed sheet is a form filled in with a pen: an unrecorded field prints BLANK (`.ds-print-blank`), ruled lines are a BORDER (backgrounds are not printed), the screen default is declared BEFORE the print block, `extraCss` lands before `@media print`, and line-height is deliberately unset.
- `brand.js` is the one palette: the text tone is the ground darkened only until it measures 4.5:1, never the raw brand colour. Server-rendered type and spacing are a CLOSED copy of the kit's resolved values; `lint.mjs` `server-css-tokens` fails any `var()` not defined there (an unknown `var()` drops the whole declaration). The icon's `font-size="120"` is an SVG attribute, not type: skip it in font sweeps.

## Auth, roles and routes (auth.js, roles.js, routes/)

- `registerAuth` order IS the security property: session -> CSRF Origin/Referer -> public routes -> `authGate` -> static. Never reorder. `/api/sync/*` is exempt from the gate only because `requireScope` bearer-gates it; `must_change_password` locks everything but change-password.
- `changePassword` re-verifies the CURRENT password (a cookie alone must not rotate it), bumps `session_epoch`, and the caller MUST re-issue the cookie at the new epoch or the person is logged out by their own change. `deleteAccount` revokes the epoch BEFORE removing the row; the last enabled admin cannot be deleted. A token with no epoch claim means 0, so shipping revocation logs nobody out. Epochs are written as strings (busybase columns are TEXT). Self-revoke uses `req.caseyAccount.id`, never params.
- No bearer token or `?token=` anywhere. `secretary` is a legacy alias of `operator` (never created new); `agent` is the unclaimed marker, never a person. `x-view-as` is admin-only and read-only through `roleGate`.
- `roleGate` decides on the lower-cased prefix (Express matches `/API` too); media is exactly `/media/<caseId>/<file>` after decoding, served with `nosniff` and `Content-Disposition` (bytes and extension are contact-chosen, same origin as the operator session); the viewer allowlist holds only routes audited PII-free; a write naming `expected_ref` that differs from the URL case is refused with 409.
- Public `/report`: served only when `CASEY_PUBLIC_URL` is set (else an unadvertised open write surface). The ref is the secret: a bare phone reaches only the web case this form opened, may add but never overwrite fields (`mergeReport` overwrites), and never sees the ref. Redirect queries carry codes (`?err=`), never sentences (forged branded copy). Refusals re-render (works without JS); success stays PRG. The rate limit guards queue VOLUME, not ref guessing: per-IP, loose (CGNAT), reads and writes budgeted separately. The field list derives from `report-shape`, one list for render and write allowlist. The page is inline CSS, light-only, carries no HTML comments (metered bytes) and promises no time, visit or person.
- `/api/ready` is ungated, PII-free, a closed vocabulary, never a model or URL; degraded stays 200, only a dead store is 503; busy retries once, then `store:'busy'`.
- `cases.js`: `export.csv` registers before `/:id`; GET, PATCH and transition share one detail projection. Reply refuses an opted-out case server-side; it claims only an unowned case, before the outbound event, and clears needs-human/ai-offline only after delivery. PATCH `expected` compares as strings against column defaults (autonomy `auto`, case_type unset). Undo is bounded to 120 s, `created_at` is unix SECONDS (`toDate`), compensating events are skipped, the reverse edge is pre-validated. Bulk validates once and caps tag/note length.
- `map.js`: dispatch only queues a suggestion, never sends; coordinates carry `location_source` so a guess never reads as GPS; the memo keys on id/`_version`/`updated_at`, never a clock (field logins bypass it). `reports-map.js` is viewer-reachable: sanitise free-text labels, 0.01 degree, week-only dates. `translate.js` handles one inbound message, cached, `recordHealth:false`. `sync-api.js` forces status `proposed` and limits per key id.

## Console UI (public/src)

- Kit/webjsx traps: dropdown triggers (account-menu, notifications-center, filters-bar) return an ARRAY, not a vnode with children (the kit rewrap reads `child.children`, webjsx stores `props.children`: empty button). webjsx cannot morph a bare-string child or a different element type in one unkeyed slot: keep one element type plus keys (login-gate), never swap a button's text mid-action (toast-tray undo uses `disabled`). `Btn` hardcodes `type=button`, so login-gate needs a raw submit; array children need an explicit `aria-label`. Wrap free text in its own span/h2 with `min-width:0` and bound it (`MAX_LEN` 4000, state the truncation): an unbreakable run in a wrapping flex froze the renderer.
- Accessibility: dialog-shell restores focus by node plus signature (polls detach the opener), gives `trapTab` the `currentTarget`, stops Escape (else `keyboard.js` back() closes the case), focuses once per open in a macrotask. Never state anything by hue or hover-only title (staff use phones). `role=button` answers Enter and Space; no `aria-selected` on a listitem; an empty scroll region needs a focusable child. One h1 per screen (`view-title`); content-swap panels render BODY only (app-view owns title and back); never register a `map` panel. `case-row` stays off the kit Row so active, selected and keyboard-focused differ.
- Data safety: fields-editor sends only changed fields with expected values (409 on collision) and reloads BEFORE dropping the draft. Mutate state through `setActiveId`/`setAttention`/`setConnLost` and the bounds setters (they publish to the imperative map); `setConnLost(false)` must not clear `sessionRestored`; `defaultMapFilter` stays in `map-model.js` (import cycle); case-detail-view sets `_loadedFor` before its await (404 retry storm). Sends to a person share one in-flight flag (reply-box `_replySending`); bulk remind is confirm-gated; duplicates are unrecoverable. The `'opted-out'` literal in reply-box and todo-hint must track `OPTED_OUT_TAG`. No language guessing.
- Lists and urgency: case-list-view filters client-side (the 5 s poll overwrites server narrowing), on PII-free fields only, and always states the true server total beside a cap. Urgency comes only from `urgencyBand` on the server rank; a chip count equals the filter it applies. Health banners are exception-only (dashboard-only mode is not a fault).
- Network: every fetch goes through `api()` with `FETCH_TIMEOUT_MS` (a hung promise latches single-flight guards). A service-worker offline answer is a RESOLVED 503 `{"error":"offline"}`: never infer link health from settling; assume a cached session on offline, never on 401. Cache only last-known whoami/branding/config, never case rows. Conditional GET: 304 returns the remembered body; drop it on non-2xx, no ETag, login and logout (no cross-session bodies). Polls (metered link) gate on `state.authed`; attention and map pins share a tick; the list ladder maximum is `ATTENTION_POLL_MS`.
- Auth UI and routing: login-gate forces step two on `must_change_password` (the reload watcher too), shows identical failed-login text for a wrong password and an unknown user, and only a POSITIVE flag holds the session. `field-app` and `viewer-app` only shape the UI; `roles.js` is the fence. nav-config handlers stop the anchor default (it wipes `#home=`), hide actions only on an explicit capability false, apply the role floor before a deployer hide, and `panelTitle` reads RAW sections. `route.js` keeps no secrets in the hash and applies home, case, then panel. Tab title only via `setBaseTitle`; key per-operator state on username.
- Map: tile URL comes from the shell meta with a same-origin `/tiles` fallback; never hardcode OSM (it leaks outbreak location). Frame the view BEFORE adding `tileLayer`, fit once, skip `invalidateSize` while hidden (0x0 moves the centre). A pin click selects via `setActiveId` with no popup. Marker colour is status (green = done only), border is provenance, size+ring is urgency; whitelist values in marker HTML, use `title` not `alt` on a `divIcon`, rebuild only on a signature change (a rebuild collapses clusters). A failing load plus `schedule()` in `onError` is a microtask loop that freezes the tab: keep the attempted-element guard, `RETRY_MIN_GAP_MS`, `INFLIGHT_STALE_MS` and clear `inFlight` in `finally`. `map-model.js`: one predicate and one count source; a no-coordinate case is never dropped by the extent filter. `reportedDiseaseNames` must not be renamed (it is not a diagnosis); diagnostics carry counts only.
- Panels: `panel-load` sets `loaded` true on failure too (else a refetch loop), shows a skeleton only while `loading && !loaded`, keeps its generation counter, and takes `what`/`label` as functions (config exists only after module eval). `known-values` renders synchronously and fetch-free, loads once per TTL, and canonicalize never blocks Save. `vocabulary.js` never spells "casey", "case" or tier names; its tier ladder mirrors `contact-tiers.js`; the `format.js` health table is `ALL_HEALTH_TAGS`. contacts-panel Erase stays low emphasis; an invite's plain code appears only in the create response; CSV is formula-escaped.

## Stylesheets (public/app.css, public/src/views/*.css)

- Ground and scope: key the html root off `data-casey-theme` with `--paper`/`--ink`, never `--bg` (theme.js sets auto and `--bg` then follows the device: a white root under a dark app). Keep the `.ds-247420` prefix on rules touching `btn-link`, dropdown triggers, h2/button sizes and `.app-chrome`/`.app-status`: kit scoped rules beat a bare class whatever the load order.
- Contrast (4.5:1 text): never `--accent-ink` or `--sky` on `--bg-2`, never a `--danger` fill as text, never opacity dimming; use `--fg-2`/`--fg-3`, `--danger-ink`, `--ink` on `--warn`, `--green` on the dark Done pill. Leaflet clusters and controls have fixed light backgrounds: pin their text to `--ink` or themed text drops to about 2:1 in dark.
- Layout: the rail never gets `overflow:hidden` without an inner scroller (`.ds-rail-stack` scrolls, else case detail is unreachable); the Back row is sticky on an opaque ground, the case header is not; the rail is docked, never floating over the map. On a phone hide map/list with `display:none`, never unmount (Leaflet keeps its viewport). `.ds-map-shell`'s chrome layer keeps `pointer-events:none` or the map cannot be dragged. Phone header: `span.crumb-right` must claim the row, the track floor is 5.75rem, z-index sits above Leaflet's 400-1000, and the login banner is selected as the gate's sibling (the gate is fixed at `--z-modal`). Gutters collapse at the kit's 480px; phone rules come last (equal specificity).
- Urgency is size, ring and a short flag, never hue alone or a full-height stripe (stacked rows merge into one line); keep the `:not(.active/.selected)` guards; words and `aria-label` also carry it. The pulse is bounded to about 6 s (WCAG 2.2.2); reduced-motion drops motion but keeps ring and size; each sheet guards its own transitions.
- Touch and text: the 44px touch floor must outrank the kit's `.btn-sm`, and the icon-only nav toggle needs its padding reset or it collapses. Under forced-colors, fields keep a zero-specificity outline so the kit focus ring still wins. `td` uses `overflow-wrap:break-word` plus `min-width`, never `anywhere` (it collapses min-content so scroll never engages); not `th`. Flex items holding contact text take `min-width:0` and wrap.

## Backup (src/backup.js)

- A raw-copy fallback must include the `-wal`/`-shm` sidecars; restore removes any stale sidecar (sqlite would replay the old WAL over the restored file); a non-empty target is refused, never merged; the live data dir is moved aside, not overwritten.

casey dashboard server.js serves the shell with a SHELL_BUILD_ID that hashes size+mtime of public/, the linked bundles, the module graph, the resolved brand, the tile URL and the vocabulary; the service-worker cache name carries it, so a changed shell is a different cache and a cache built for one build can never serve another. Any new input to the served shell must be hashed in, or the worker keeps serving old bytes after a deploy. mtime is used because the supervisor already recycles the worker on it, so the process that recomputes the id is the one a source edit restarts. Brand, tile URL, vocabulary and the generated modulepreload block are rewritten into the SERVED bytes only, never into index.html on disk: it stays casey's default for a bare clone, and brand.js reads that file's theme-color as its fallback, so rewriting it would make brand.js read its own output. Modulepreload tags carry no crossorigin attribute (it would make the preload cache key disagree with the import and fetch every module twice), cover static import specifiers only (a dynamic import is deferred and a preload of it produces Chrome's preloaded-but-not-used warning), and must never reach /design/dist/247420.js: that bundle is 355,065 gzipped bytes for a strict superset of what the ds/ sources already deliver, so there is no /design-sdk-shim.js route and no importmap entry for it. Static files revalidate every time because no URL carries a content hash and a stale shell against a newer API is a safety problem on a triage dashboard; the service worker is the speed layer, keyed by SHELL_BUILD_ID so it can answer with no revalidation and still never outlive a deploy. /api/, the public /report form and basemap tiles are never in Cache Storage (tiles are bounded by the server-side LRU; a browser copy would be unbounded and thrown away each deploy). skipWaiting is deliberate: a deploy that waits for every tab to close could take days to reach an operator, and the mixed-version window is bounded because the new worker serves one whole consistent build.

casey's contact access ladder lives in src/contact-tiers.js. TIER_ORDER from low to high is reporter, field_worker, animal_health_technician, operator. Every permission question asks 'at least rung N' via atLeast/canQueryCases; testing for exactly N (for example === 'field_worker') is a silent bug as soon as another rung sits above it. resolveTierValue is fail-closed: it maps a missing, empty, pre-migration or corrupt tier to the LOWEST rung. Rung powers: reporter is the default and can file or amend its own report plus REPORT_ONLY_TOOLS; field_worker adds the enquiry tools and location check-ins; animal_health_technician has EXCLUSIVE authority to move a report to done; operator adds team management. The per-tool minimum rung table is TOOL_MIN_TIER in case-tools-gates.js.

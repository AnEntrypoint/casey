In casey, report-fields.yml declares the report fields[] (flags critical_for_visit, append, never_inferred, system_set, severity_signal) plus the gate/signoff/area blocks (mandatory_minimum, signoff_diagnosis, area_field, geo_fields) and dashboard_ui which is DISPLAY only. severity_signal is presence-based: its presence raises attention rank (attn.js adds +7) and it carries no magnitude except a numeric ZERO. persona.cjs declares prompt TEXT (agentName, noticeVersion, noticeAnchor) while caseSystemPrompt owns STRUCTURAL prompt logic. vocabulary.yml is the one file of human-facing words, applied by applyVocabulary() which is pure and falls back per absent key. src/store/report-shape.js is the single choke point where every derived shape constant (keys, critical/mandatory/signoff fields, area field, labels, sections) is exported and every consumer imports it; deriveReportShape(reportFields) is the same derivation as a pure function for running MULTIPLE schemas in one process.
